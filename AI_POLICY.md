# AI policy

AI tools are welcome here. The rules are short:

1. **Disclose it in the pull request.** Name the tool (for example Claude Code, Cursor or
   Copilot) and say in what way it was used: ideas, boilerplate, tests, parts of the code or
   text. The pull request template has a section for it.
2. **No attribution in commits needed.** Leave out `Co-authored-by:` lines or "Generated with"
   notes for AI tools. The disclosure in the pull request is enough.

With or without AI, you stand behind your change like any other: you understand it, and you
answer the review yourself.

## How the maintainer uses AI

I'm not a vibe coder. I use AI to speed up development, mostly for ideation and boilerplate.
I read all of the code, and every change has to meet my quality bar before it lands.
